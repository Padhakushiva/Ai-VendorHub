## 📊 Key Concepts

### Component Structure
```
App (Main)
├── Navbar (Search & Navigation)
├── Home / ProductDetail (Pages)
│   ├── HeroSection
│   ├── FilterSidebar
│   ├── ProductGrid
│   └── ProductCard (Reusable)
└── Footer
```

### State Management
```
ProductContext (Global)
├── Products List
├── Loading State
├── Error State
└── Filters
    ├── Search Term
    ├── Category
    └── Price Range
```

### Data Flow
```
User Input → Component → Update Filter → 
Context Update → API Call → 
Products Updated → UI Re-renders
```

## 🔄 Common Workflows

### Getting Data from Backend
1. User triggers filter/search
2. `ProductContext.updateFilters()` called
3. `useEffect` detects change
4. `fetchProducts()` makes API call
5. Results update automatically

### Adding a New Component
1. Create file in `src/components/`
2. Import in parent component
3. Pass props as needed
4. Add to component hierarchy

### Customizing Styling
1. Edit `tailwind.config.js` for global colors
2. Or use inline Tailwind classes
3. Or create custom CSS in `App.css`
4. Hot reload shows changes instantly

### Debugging Issues
1. Open DevTools: `F12`
2. Check Console tab for errors
3. Check Network tab for API calls
4. Check Application tab for state
5. Use `console.log()` to debug
